# 浪花亭ごん太の世界ボヤき帳 — 連載仕様

毎朝 6:00 JST に、前日の世界の時事ネタを題材にした読了5分のエッセイを Notion に投稿する連載の仕様書。

## 概要

| 項目 | 内容 |
| --- | --- |
| 配信時刻 | 毎日 6:00 JST（cron `0 21 * * *` UTC） |
| 投稿先 | Notion データベース「ボヤき帳アーカイブ」 |
| データソースID | `collection://9b06dc79-032f-44e8-a427-67a773346e1e` |
| 題材 | 前日（JST）の世界の時事ネタ 4〜5本 |
| 分量 | 日本語 2,400〜2,800字（読了5分） |
| 語り手 | 浪花亭ごん太（本連載のための架空の関西芸人キャラクター） |

このリポジトリには記事本文は保存しない（Notion のみ）。ただし Notion コネクタが使えなかった
場合に限り、記事を失わないよう `entries/YYYY-MM-DD.md` に退避する。

## 設計上の決定事項

### 1. 実在の芸人名は使わない

「大物関西芸人の視点」という企画意図は、**オリジナルの架空キャラクター**で実現する。
実在の芸能人の名前を冠して架空のコメントを書くと、本人が発していない意見を本人の発言として
流通させることになるため。記事末尾には毎回その旨のお断りを入れる。

### 2. 事実とボヤきを視覚的に分ける

各ネタは「事実の callout（📌・グレー背景）」→「ボヤきの地の文」の順で構成する。
読者が「どこまでが報道で、どこからが語り手の意見か」を一目で判別できるようにするため。
主観には文末に「知らんけど」を付け、意見であることの印として機能させる。

### 3. 死者・負傷者が出た話は茶化さない

そのネタではボケを一度やめ、静かな敬意をもって短く書く。連載の信用はここで決まる。

### 4. JST で日付を確定する

旧ルーティン（`朝のまとめ`）は、セッションの UTC 日付をそのまま使っていたため、
JST 6:00 の実行が前日付のファイルになり、本文も前日の天気を「今日」として配信していた。
本連載のプロンプトでは冒頭で `TZ=Asia/Tokyo date` を実行し、JST の日付を使うことを必須にしている。

### 5. 毎日ちがう切り口にする

執筆前に Notion のデータソースを fetch して直近5件のタイトルとリードを読み、
同じ型（数字で並べる、時間軸で並べる等）を連続で使わないようにする。
テンプレートをなぞるだけの記事にしないための仕組み。

## 記事の構成

1. 冒頭 callout（orange_bg）— 日付と一行のつかみ
2. `## つかみ` — 挨拶から入り、今日の切り口を提示
3. `## 本日のお品書き` — 取り上げる4〜5本を番号付きリストで
4. 区切り線
5. 本編 — ネタごとに `## 見出し` ＋ 事実 callout ＋ ボヤき3〜5段落
6. 区切り線
7. `## オチ` — 読者が今日をどう過ごすかに着地。「ほな、また明日。」で締める
8. 語り手についてのお断り callout
9. `## ネタ帳（出典）` — 全ソースのリンク

## Notion データベースのプロパティ

| プロパティ | 型 | 内容 |
| --- | --- | --- |
| タイトル | title | 切り口を表す記事タイトル |
| 日付 | date | JST の配信日 |
| テーマ | multi_select | ロシア・ウクライナ／欧州政治／米中／中東／経済・物価／アジア／アメリカ政治／国際機関 |
| リード | text | 一覧に出る1〜2文のサマリー |
| 読了目安（分） | number | 5 |

## Routine のプロンプト

実際に毎朝実行されるプロンプトは [`docs/boyaki-cho-prompt.md`](./boyaki-cho-prompt.md) に保存している。
Routine を作り直す場合はこのファイルの内容をそのまま貼り付ける。

## 実行の仕組みと既知の制約

### API からはコネクタを付けられない

`create_trigger` API は、この組織では `connectors` パラメータが利用できない
（`the connectors parameter is not available for this organization`）。
そのため API 経由で作成した「新規セッションを起動する Routine」には Notion コネクタが紐づかず、
発火したセッションに `mcp__Notion__*` ツールが一切存在しない（検証用 Routine を実際に発火させて確認済み）。

### 現在の運用：セッション常駐方式

代替として、**Notion コネクタを保持しているセッションを毎朝起こす** Routine を使っている。

| Routine | ID | 状態 |
| --- | --- | --- |
| ボヤき帳 6:00JST（セッションを起こす） | `trig_012iqDsiPN6rgFM549aeguBU` | 稼働中 |
| ボヤき帳（新規セッション版） | `trig_01SSrtk86YH2mLHfci1eq29j` | 停止中（予備） |
| 旧・朝のまとめ | `trig_01AKrg4MAZEsNCYA1BrK7AMW` | 要・手動停止 |

この方式の弱点は、**対象セッションが失われると連載が止まる**こと。
セッションはいずれ回収されるため、恒久的な運用には次の「本来の解決策」が必要。

### 本来の解決策

claude.ai の Routines 画面から、**Notion コネクタを有効にした状態で** Routine を新規作成する。
貼り付けるプロンプトは [`docs/boyaki-cho-prompt.md`](./boyaki-cho-prompt.md) にある。
作成できたら、上表の Routine はすべて削除してよい。
