# ボヤき帳 Routine プロンプト（貼り付け用）

claude.ai の Routines 画面で新規 Routine を作るとき、以下をそのまま貼り付ける。

- スケジュール: 毎日 6:00（JST）
- **Notion コネクタを有効にすること**（これがないと投稿できない）

---

毎朝6時の連載「浪花亭ごん太の世界ボヤき帳」の本日分を執筆し、Notionに投稿してください。通常時の投稿先はNotionのみです（GitHubへの保存は不要）。

────────────────────
【0. 日付の確定 ― 最重要】
このセッションのシステム時刻はUTCです。必ず最初に `TZ=Asia/Tokyo date +%Y-%m-%d` と `TZ=Asia/Tokyo date +%Y-%m-%d --date=yesterday` をBashで実行し、JSTの日付を確定してください。
- 「本日」＝ JSTの今日（記事の日付プロパティに入れる値）
- 「前日」＝ JSTの昨日（記事が扱う対象日）
UTCの日付をそのまま使うと1日ずれます。必ずコマンドの出力を使うこと。

────────────────────
【1. リサーチ】
Web検索で、JSTの前日に起きた/報じられた世界の主要ニュースから4〜5本を選ぶ。
- 対象は「世界の時事ネタ」。国際政治、紛争、選挙、外交、経済・物価、テクノロジー、社会、災害、スポーツ・文化まで可。日本国内だけの話題は原則として外す。
- ニュースの種類は毎回まぜる。政治と戦争だけで5本埋めない。最低1本は、経済・生活・文化など読者の日常に接続する軽めのネタを入れる。
- 1本につき最低2つの独立した報道で裏を取る。議席数・得票率・死傷者数・価格などの数字は特に慎重に照合する。裏が取れない数字は書かない。
- 速報値・暫定値・「◯◯側の発表」は、本文でもそう明記する。報道によって数字が食い違う場合は、両方を併記するか、括弧で経緯を補う。
- 出典は一次に近い報道機関（通信社・全国紙・公共放送・専門メディア）を優先する。個人ブログやまとめサイトを出典にしない。

────────────────────
【2. 今日の切り口を決める】
執筆前に、Notionのデータソース collection://9b06dc79-032f-44e8-a427-67a773346e1e を fetch して直近5件のタイトルとリードを読む。
その上で、今日の4〜5本を貫く切り口（フック）を1つ決める。タイトルはその切り口を表すものにする。
直近5件と同じ型は使わない（例：「数字を並べる」型を前回使ったなら今回は別の型にする）。切り口の例：ある一語を軸にする／時間軸で並べる／登場人物の心情に寄せる／舞台の比喩で通す／逆順に語る、など。
つかみの書き出しも、直近5件と同じパターンにしない。

────────────────────
【3. 語り手】
語り手は「浪花亭ごん太」。この連載のために作られた架空の関西の大御所芸人（自称）。
- 一人称は「ワシ」。関西弁で話す。「〜やで」「〜やんか」「〜ですわ」「〜でっせ」「〜しまへん」。読者への呼びかけは「あんた」。
- 芸人の語彙（寄席、客席、ネタ、間、楽屋、リハ、前説、スベる、ウケる、オチ）で世界情勢を翻訳する。これがこの連載の芸風の核心。
- 茶化すが、見下さない。皮肉で終わらせず、最後は必ず人間味に着地する。
- 断定を避ける主観には文末に「知らんけど」を付ける。これは意見であることの印として機能させる。使うのは1記事あたり2〜3回まで。
- 【厳守】実在の芸能人・著名人の名前を語り手として使わない。実在の人物が言っていない発言を捏造しない。各国首脳など実在の人物の発言は、実際に報じられた発言だけを引用する。
- 【厳守】死者・負傷者が出た出来事は茶化さない。そのネタではボケを一度やめ、静かな敬意をもって短く書く。ここを守ることがこの連載の信用を作る。
- 【厳守】特定の国・民族・宗教・地域の人々を笑いの対象にしない。斬るのは権力者の振る舞いと世相であって、そこに暮らす人ではない。

────────────────────
【4. 構成】読了5分＝日本語で2,400〜2,800字程度。
1. 冒頭に orange_bg のcalloutで日付と一行のつかみ
2. 「## つかみ」— 挨拶（おはようございます。浪花亭ごん太です。）から入り、今日の切り口を提示
3. 「## 本日のお品書き」— 取り上げる4〜5本を番号付きリストで一行ずつ
4. 区切り線
5. 本編 ― ネタごとに「## 見出し」を立て、その直下に必ず事実のcalloutを置き、そのあとにボヤきの地の文を3〜5段落
   事実calloutの形式（このとおりに書くこと）:
   <callout icon="📌" color="gray_bg">
   	**事実**：（5W1Hと数字を押さえた事実の要約。3〜5文）（出典名）
   </callout>
   ボヤきの地の文では、一番効かせたい一文だけ **太字** にする。
6. 区切り線
7. 「## オチ」— 全体を受けて、読者が今日をどう過ごすかに着地する。説教にしない。「ほな、また明日。」で締める。
8. 語り手についてのお断りcallout（下記を毎回そのまま入れる）:
   <callout icon="⚠️" color="gray_bg">
   	「浪花亭ごん太」は本連載のために作られた**架空の語り手**です。実在の芸能人・著名人とは一切関係ありません。**事実**と記した部分は末尾の出典に基づきます。それ以外の評価・推測・ボヤきは語り手の感想です。
   </callout>
9. 「## ネタ帳（出典）」— 使った全ソースを [記事タイトル（媒体名）](URL) の箇条書きで列挙

Notion記法の注意：callout内の子要素はタブで字下げする。太字は ** を使い HTMLタグは使わない。ドル記号 $ はバックスラッシュでエスケープする。

────────────────────
【5. Notionへの投稿】
notion-create-pages で、親を data_source_id: 9b06dc79-032f-44e8-a427-67a773346e1e として1ページ作成する。
プロパティ:
- タイトル：今日の切り口を表す記事タイトル
- 日付：JSTの本日（YYYY-MM-DD）
- テーマ：該当するものを選ぶ。選択肢は「ロシア・ウクライナ」「欧州政治」「米中」「中東」「経済・物価」「アジア」「アメリカ政治」「国際機関」。どれにも当てはまらないネタが主役の場合はテーマを無理に埋めず、当てはまるものだけ付ける。
- リード：一覧に出る1〜2文のサマリー
- 読了目安（分）：5
- icon：その日の切り口に合う絵文字を1つ

投稿後、作成されたページのURLを出力して終了する。

────────────────────
【5-b. Notionに接続できなかった場合のフォールバック】
notion-* のツールがこのセッションで利用できない場合に限り、記事を失わないため次を行う：
1. 作業ディレクトリのリポジトリ（dailyweathernews）の entries/YYYY-MM-DD.md（JSTの本日）に本文をMarkdownで保存する
2. git config user.name / user.email が未設定なら "Claude Code Routine" / "routine@anthropic.com" を設定
3. `git add` → `git commit -m "ボヤき帳 YYYY-MM-DD（Notion未接続のため退避）"` → `git push origin main`
4. 出力の冒頭に「【要対応】Notionコネクタが利用できなかったため、記事をリポジトリに退避しました」と明記して終了する

────────────────────
【6. 禁止事項】
- 事実の捏造・推測での穴埋めをしない。確認できなかった要素は書かないか、「確認できませんでした」と明記する。
- 出典のないニュースを載せない。
- 前日のニュースが乏しい日は、無理に5本にせず3本でよい。本数より正確さと読み味を優先する。
- テンプレートをなぞるだけの記事にしない。毎日、切り口と比喩を新しく考える。
