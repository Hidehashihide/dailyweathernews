# 企画書 #3 『MY FAKE MUSEUM』（マイ・フェイク・ミュージアム）

**仮邦題：ぜんぶ嘘の博物館**
バズスコア **59 / 70（本ポートフォリオ最高）** ｜ ベット経路：**UGCプラットフォーム内爆発（Grow a Garden / Steal a Brainrot 型）**

## 1. ログライン

> **ゴミを拾って「これは古代王の涙です」と書いて展示する。信じた客が金を払う。夜、隣の館長がそれを盗みにくる。**

## 3. なぜ今これか（市場根拠）

- Roblox DAU 1億3,200万（2026Q1）。**2026年8月のモバイルDL世界1位**（2,177万DL）。売上は前年比 +36%。
- **Grow a Garden / Steal a Brainrot / 99 Nights in the Forest の3本は、いずれも月間エンゲージメント時間で Fortnite バトルロイヤルを上回った。**
- **Steal a Brainrot は開発4ヶ月・若い少人数チームで、同接2,580万・月商$10〜11M** に到達。参入コストと期待値の比が異常に良い。
- クリエイター還元は2025年に **15億ドル超**（前年比+70%）、トップ1,000開発者の平均が **年間約98万ドル**。
- **Grow a Garden 2（2026年6月）が続編でPvP「他人の畑から盗む」を追加した**＝プラットフォームの成功者自身が「所有と略奪」に回帰している。この方向は確定的。

### 空いている穴
Roblox上位群は全て「**育てる → 奪う**」である。だが **「言葉」を資産にした作品がない**。
Robloxの文化はミーム（brainrot）＝**言葉そのもの**で動いている。**キャプション（説明文）をプレイヤーに書かせれば、プラットフォーム文化とゲームメカニクスが直結する。**

## 4. コアループ

```
[採集] マップのガラクタを拾う（空き缶、折れた枝、誰かの靴）
  ↓
[捏造] 展示ケースに入れ、キャプションを自分で書く
       例：「初代館長が最後に飲んだコーヒー（1847年）」
  ↓
[開館] 他プレイヤーが自分の博物館に来館する
  ↓
[査定] 来館者が「本物だと思う / 嘘くさい」を投票し、チップを置く
       → 説明が面白い/それっぽいほど儲かる
  ↓
[夜] 略奪フェーズ。他人の館から展示品を盗める
  ↓
[書き換え] 盗んだ品は**由来を書き換えて**自分の館に展示できる
  ↓ （ループ）
```

**この設計の核**：**ゲームの価値がプレイヤーの書いた文章に宿る。** アセット制作コストがほぼ増えないのに、コンテンツは無限に増える。

---

## 5. 詳細ルール

### 5-1. 査定システム（収益の源泉）
| 来館者の行動 | 効果 |
|---|---|
| 「本物だ」投票 | 館の**権威スコア**が上がる → 高級な展示ケースが解放される |
| 「嘘くさい」投票 | **話題スコア**が上がる → 来館者数が増える |
| チップ | そのまま通貨 |

**重要**：権威と話題は**どちらも正解**。真面目に本物っぽく書く人と、全力でふざける人が同じ土俵で勝てる。→ プレイヤー層が割れない。

### 5-2. 略奪フェーズ（夜）
- 1日のうち **8分間だけ**「夜」になり、他人の館に侵入できる。
- 盗めるのは **展示品1つ / 1回**。警備員（Robux/通貨で雇用）が配置されていると弾かれる。
- **盗まれた側には「盗難事件」として館の壁に記録が残り、来館者数が逆に増える**（＝盗まれ損にならない）。
- 盗品には **「盗品ラベル」が永久に残る**。由来を書き換えても消せない。これが対立と物語を生む。

### 5-3. ギルド（博物館協会）
- 最大20人。協会単位で週次ランキング。
- 協会は **共同展示室**を持てる。メンバーが1つずつ持ち寄って「テーマ展」を開催できる。
- 他協会の共同展示室は **盗めない**（大規模な荒らしを防ぐ）。

### 5-4. 週次「本物ガチャ」
- 週に1回だけ、**本当に価値のある品**がマップに1個だけ湧く（サーバー全体で1個）。
- これを取ったプレイヤーは1週間、全サーバーの検索上位に表示される。
- → **ミーム代謝の受け皿**。その週に流行っているネタを毎週この「本物」として実装できる。

## 6. バズ設計

### 6-1. 7原則マッピング

| 原則 | 点 | 実装 |
|---|---|---|
| ①5秒ルール | **8** | 「空き缶に大げさな説明文がついている」画は5秒で伝わる。ただし読字が要る |
| ②失敗こそコンテンツ | **7** | 渾身のキャプションが「嘘くさい」全票／警備を雇った翌日に盗まれる |
| ③人間が乱数 | **9** | **コンテンツの中身が100%プレイヤーの文章**。運営の想像を超え続ける |
| ④摩擦ゼロ | **9** | Roblox内＝DL済み、無料、リンク1つで友達が入れる |
| ⑤日常寄生 | **6** | 来館とチップはオフライン中も発生。ただし略奪は在席が要る |
| ⑥所有と略奪 | **10** | 育成・収集・強奪・書き換え・盗品ラベルまで一気通貫 |
| ⑦ミーム代謝 | **10** | **週次「本物ガチャ」がミーム投入の常設スロット**。72時間で流行を実装できる |

### 6-2. 想定クリップ（具体的に3本）

1. **「キャプションが上手すぎる」**
   ただの石に、本物の博物館みたいな学術的キャプションが付いていて、全員が「本物だ」に投票してしまう。
   → スクショだけで完結し、X / TikTok の両方で拡散する。**言葉はスクショで拡散するので、動画不要**。

2. **「盗品ラベル戦争」**
   Aが盗んだ品をBが盗み返し、盗品ラベルが3段になる。キャプションが「Aから奪還した、元はBの所有だった、本来は誰のものでもない石」になる。
   → 物語がプレイヤーの手で生成される。

3. **「週次の本物を取った瞬間」**
   サーバーに1個だけ湧く本物を巡って20人が殴り合う。取った瞬間に全サーバーに名前が出る。
   → 配信の山場が毎週決まった時刻に来る（配信者が予定を組める＝定期的に配信される）。

### 6-3. 拡散の仕掛け
- **キャプションのスクショ共有ボタン**：展示ケースを1枚のカード画像として書き出し、その場で共有できる。**Robloxで文章が拡散するのは希少で、それ自体が新規性になる**。
- **「今週のベストキャプション」を公式が毎週選出**し、公式SNSで紹介 + ゲーム内の殿堂に永久展示。→ 投稿する動機が生まれる。
- **モデレーション**：キャプションは全文フィルタ＋通報＋殿堂入り前の人間レビュー。**Robloxの年齢層を考慮し、ここは絶対に手を抜かない**（下記リスク参照）。

## 7. 収益モデル（Robux）

| 商品 | 価格帯 | 内容 |
|---|---|---|
| 展示ケース（ガラス/大理石/金） | 50〜800 Robux | 見た目＋権威スコア補正 |
| 照明・音響 | 100〜400 Robux | 来館者の滞在時間が伸びる |
| 警備員 | 200 Robux / 3日 | 略奪を弾く（**恒久ではなく期間制＝リピート課金**） |
| 展示枠の拡張 | 300〜2,000 Robux | 同時展示数を増やす |
| 協会バナー | 1,500 Robux | 協会全員に表示 |

**売らないもの**：チップ収入の直接購入、キャプションの評価操作。**経済の根が「文章の面白さ」である以上、そこを金で買えるようにすると全部壊れる。**

**試算**
| シナリオ | DAU | 月商 |
|---|---|---|
| 保守 | 5万 | 約 $60K（900万円） |
| 基本 | 40万 | 約 $400K（6,000万円） |
| 上振れ | 500万 | 約 $3M（4.5億円） |

**損益分岐：DAU 約8,000**（初期投資900万円）— 極めて低い。

## 9. KPI と撤退基準

| 指標 | 目標 | 撤退ライン |

| キャプション記入率 | 70%以上 | **40%未満ならゲームが成立しない → コア再設計** |

| 盗まれた側のD1 | **盗まれていない人と同等** | **10pt以上落ちるなら略奪設計を緩める（最重要指標）** |
| I値 | 1.5 | 1.0未満なら協会設計をやり直し |
| 不適切キャプションの検出漏れ | **0.1%未満** | **0.5%超えたら公開を停止する（例外なし）** |

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **未成年ユーザーへの不適切テキスト** | **致命的・事業停止級** | 多層防御：①Roblox標準フィルタ ②自社NGリスト ③LLMによる文脈判定 ④通報1件で即時非表示 ⑤殿堂入りは人間レビュー必須。**モデレーション予算を開発費の15%として最初から確保** |
| プラットフォーム依存（Robloxの規約変更・収益率変更） | 大 | 本企画は**900万円の検証投資**と位置づける。当たったら Steam / モバイルへ独立版を展開（コアは移植可能な設計にしておく） |
| 略奪で新規が離脱 | 大 | 初週は略奪対象外（ビギナー保護）／盗まれても来館者増で得をする設計／**恒久資産は奪われない** |
| キャプションが書かれない（読み書きの負担） | 大 | **定型文ガチャ**を用意（「これは○○の△△である」の穴埋め）。書ける人は自由入力、書けない人は穴埋めで参加できる |
| Steal a Brainrot の亜種扱い | 中 | 「盗む」ではなく **「盗んで由来を書き換える」** が本作の固有性。トレーラーと1枚絵はキャプションを主役に |
| 運営の属人化（Grow a Garden の失速原因） | 中 | 週次イベントを**テンプレ化して3ヶ月分を事前制作**。担当が1人抜けても回る状態で公開する |

## 12. 補足：この企画を最優先で作るべき理由

1. **初期投資900万円** ＝ 5企画中で最小。損益分岐がDAU 8,000と極端に低い。
2. **4ヶ月で市場に出せる** ＝ 「バズの7原則」が自社で再現できるかを最速で検証できる。
3. Robloxは**マーケティング費がほぼ不要**（プラットフォーム内のアルゴリズム発見が支配的）。
4. 失敗しても **損失が小さく、UGCプラットフォームの運営ノウハウが残る**。
5. 当たれば **Steal a Brainrot 級（月商$10M）の上限**がある。

→ **#1 GHOST CROWD のプロトタイプと並行して、本企画を先に出荷することを推奨する。**
