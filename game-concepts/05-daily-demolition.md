# 企画書 #5 『DAILY DEMOLITION』（デイリー・デモリッション）

**仮邦題：今日の解体**
バズスコア **51 / 70** ｜ ベット経路：**短尺動画ネイティブ ＋ 毎日習慣（Wordle × Block Blast 型）**

---

## 1. ログライン

> **今日、世界中の全員が同じ1つの建物を壊す。あなたのスコアは、全員と直接比べられる。**

---

## 2. 企画概要

| 項目 | 内容 |
|---|---|
| ジャンル | 物理破壊パズル（ハイブリッドカジュアル） |
| プラットフォーム | iOS / Android（**縦持ち・片手・音なしで完結**） |
| 1プレイ | **45秒**。デイリーは1日1回だけ挑戦できる |
| 価格 | 基本無料。IAP（工房・シーズン・広告除去） |

## 3. なぜ今これか（市場根拠）

- **ハイブリッドカジュアルが唯一の成長領域**：2026年上半期に約 **+23%、$2.4B**。純広告型ハイパーカジュアルは単体でトップに立てなくなり、標準構成は「ハイパーカジュアルのフック ＋ メタレイヤー ＋ IAP経済」。
- **Block Blast!**（Hungry Studio）が **短尺動画UA戦略** で iOS 首位奪還 / Google Play 1位、合計 約2,500万DL。**単発バズではなく長期のグローバルヒットに移行**した。これが目指すべき形。
- **モバイルゲームの最大の競合は TikTok / Instagram / YouTube の短尺動画**。可処分時間を直接奪い合っている。
- **バズ動画に効く行為は「結合・切断・破壊・強化」** であることが分析で確定している。**破壊は最も強い。**
- しかし現在の破壊系ゲームは全て「無限に遊べる」設計であり、**「全世界が同じ1問を1日1回だけ解く」（Wordle 型）を組み合わせたものが存在しない。**

### 本企画の一点突破
**全世界が同じ盤面を解くと、短尺動画に「比較」が成立する。**
通常のパズル動画は「その人の盤面」なので視聴者は他人事だが、**今日の盤面は視聴者も解いた盤面**である。だから
- コメントする動機が生まれる（「俺は240万だった」）
- 検索需要が生まれる（「デイリーデモリッション 今日 攻略」）
- 明日も同じ時刻に話題が発生する

**つまり、UAをクリエイターとアルゴリズムに肩代わりさせられる。**

## 4. コアループ

```
[毎朝 日本時間9時] 全世界共通の建物が1つ配信される
  ↓
[45秒] スワイプで爆薬・切断・支柱除去を配置し、建物を崩す
       崩れた瓦礫の量・連鎖・かかった時間でスコア
  ↓
[結果] 世界順位・フレンド順位・国別順位が即表示
  ↓
[自動書き出し] ベストな崩壊の瞬間が **15秒の縦型動画** として自動生成される
  ↓
[共有] ワンタップでTikTok / Shorts / Reels へ。動画には「今日の盤面」リンクが埋まる
  ↓
[流入] 動画を見た人が同じ盤面を遊べる → 直接スコアを比較できる
  ↓
[メタ] 稼いだ資源で工房を強化 → 明日のデイリーで使える道具が増える
  ↓ （翌朝9時へ）
```

## 5. 詳細ルール

### 5-1. 操作（片手・縦持ち・無音で完結）
| 操作 | 効果 |
|---|---|
| タップ | 爆薬を設置 |
| 上下スワイプ | 柱を切断する高さを決める |
| 長押し | 支柱を抜く（じわじわ傾く） |
| 2本指ピンチ | 時間を0.25倍速にする（1回のみ、演出用） |

**スロー演出は意図的に「動画映え」のために入れている。** プレイヤーが自分で最高の瞬間を演出できる。

### 5-2. スコア
```
スコア = 瓦礫量 × 連鎖倍率 × 残り時間ボーナス × スタイル係数
```
- **スタイル係数**：きれいに内側へ崩す（実際の解体工法）と高倍率。適当に爆破しても点は出るが伸びない。
- → **初心者でも点は出る（快感がある）が、上手い人は5倍以上取れる**。動画で差が見える。

### 5-3. メタレイヤー（ハイブリッドカジュアルの必須要素）
| 要素 | 内容 |
|---|---|
| **工房** | 爆薬・カッター・重機をアップグレード。デイリーに持ち込める道具が増える |
| **図鑑** | 崩した建物が模型としてコレクションされる（世界の実在建築モチーフ、権利に配慮した架空デザイン） |
| **シーズン** | 6週間。テーマ（氷の街／砂の街／宇宙ステーション）ごとに建物の物理が変わる |
| **ギルド** | 30人。ギルド平均スコアで週次報酬 |

### 5-4. デイリー以外のモード（DAU維持用）
- **フリー解体**：ランダム生成の建物を無制限に遊べる。ただし世界順位には乗らない。
- → デイリーの希少性を守りつつ、遊び足りない層を受け止める。

## 6. バズ設計

### 6-1. 7原則マッピング

| 原則 | 点 | 実装 |
|---|---|---|
| ①5秒ルール | **10** | 建物が崩れる。説明が一切要らない。全言語圏で同じ |
| ②失敗こそコンテンツ | **5** | 弱い。「1本だけ残って倒れない」等はあるが、基本は成功が気持ちいいゲーム |
| ③人間が乱数 | **6** | 中程度。**全世界同一盤面だから他人の解法が価値を持つ**（人間由来の多様性がスコアに出る） |
| ④摩擦ゼロ | **10** | 無料 / 45秒 / 縦持ち片手 / 動画から1タップで同じ盤面へ |
| ⑤日常寄生 | **9** | 毎朝9時に通知が来る1日1回の習慣。**Wordle と同じ位置に座る** |
| ⑥所有と略奪 | **4** | 弱い。工房と図鑑の所有はあるが略奪がない |
| ⑦ミーム代謝 | **7** | 建物デザインで流行を取り込める。週次の特別盤面 |

### 6-2. 想定クリップ（具体的に3本）

1. **「今日の盤面、1本の柱だけで全部落ちた」**
   最小手数で全壊させる解法を見つけた人の動画。**視聴者も今日それを遊んでいるので、即座に「まじで!?」となる**。
   → コメント欄が自分のスコア報告で埋まる。

2. **「99%で止まった」**
   瓦礫が1個だけ残って99.8%。悔しさの絶叫。
   → 失敗系クリップ（原則②の補強）。

3. **「国別ランキングで日本が1位になった日」**
   国別順位が接戦になると、各国のコミュニティが動員をかける。
   → **ゲーム外の集団的な物語**が発生する。

### 6-3. 動画ネイティブ設計（本企画の中核）
| 仕掛け | 詳細 |
|---|---|
| **自動15秒縦型動画** | 最も瓦礫が動いた区間を自動検出し、スロー・カメラワーク・スコア表示込みで書き出す。**プレイヤーは編集しない** |
| **動画に盤面IDを埋める** | 共有リンクから開くと**同じ今日の盤面に直行**。ストアを経由しても復帰する（ディファードディープリンク） |
| **無音で成立** | BGM抜きでも意味が通る。TikTokは音を差し替えられるため、**音に依存しない画作り**が必須 |
| **スコアを画面に焼き込む** | 動画内に数字が入る＝コメントで比較が始まる |
| **クリエイター用「今日の盤面」API** | 配信者が自分のコミュニティ限定ランキングを作れる |

## 7. 収益モデル

| 種別 | 価格 | 内容 |
|---|---|---|
| 広告除去 | $4.99 買い切り | インタースティシャル除去（リワード広告は残る） |
| シーズンパス | $9.99 / 6週間 | 限定建物・工房素材・図鑑枠 |
| 工房パック | $2.99〜$29.99 | 素材の時短 |
| リワード広告 | — | 「今日のデイリーをもう1回だけ挑戦」（**順位は1回目のみ有効**＝ペイトゥウィンにしない） |

**重要**：**デイリーの順位は金で買えない。** 追加挑戦は練習扱い。ランキングの信頼性が本作の資産であり、ここを売ると「比較」というコア価値が消える。

**試算（基本ケース）**
- DAU 80万 × ARPDAU $0.09 = 日商 $72,000 → **月商 約3.2億円**
- 内訳目安：広告45% / シーズンパス30% / IAP 25%
- UA：初年度 3億円を想定（ただしオーガニック比率60%を目標）
- **損益分岐：DAU 約9万**

## 8. 開発計画

| フェーズ | 期間 | 内容 | ゲート |
|---|---|---|---|
| P0 | 4週間 | 物理破壊の手触り＋45秒1ステージのみ | **「崩れる瞬間」が無音15秒動画で成立するか（S値0.8）** |
| P1 | 8週間 | スコア設計、デイリー配信基盤、自動動画書き出し | 自動生成動画の「共有したい」率30%超 |
| P2 | 8週間 | 工房・図鑑・シーズン・ギルド（メタレイヤー） | D7 25%超 |
| P3 | 6週間 | ソフトローンチ（カナダ/フィリピン/トルコ） | **D1 45% / D7 25% / ARPDAU $0.05** を満たすまで出さない |
| P4 | 6週間 | 最適化・多言語・UAクリエイティブ量産 | CPI < $0.80 |

**体制**：物理エンジニア1／クライアント2／サーバ（デイリー配信・ランキング）1／アート1／プロダクト＆UA 1

**技術の要**：**全世界で同じ崩壊を再現する決定論的物理**。端末差で結果がずれるとランキングが成立しない。
→ 固定小数点演算による決定論的物理を採用し、サーバ側でリプレイを検証する（スコア偽装対策も兼ねる）。**ここが最大の技術的難所であり、P0で必ず検証する。**

## 9. KPI と撤退基準

| 指標 | 目標 | 撤退ライン |
|---|---|---|
| **決定論的物理の端末間一致率** | **100%** | **99.9%未満なら企画中止**（ランキングが成立しない） |
| S値（無音15秒動画の理解率） | 0.8以上 | 0.6未満ならP0で中止 |
| D1 / D7 / D30 | 45% / 25% / 12% | ソフトローンチで D7 18%未満なら本ローンチしない |
| ARPDAU | $0.09 | $0.04未満なら収益設計をやり直し |
| CPI | $0.80以下 | $1.50超ならUAを止めてオーガニック一本に切り替え |
| オーガニック比率 | 60%以上 | **30%未満＝動画ループが機能していない → 最重要の再設計対象** |
| 共有率（プレイあたり） | 12% | 4%未満なら書き出しUIを全面刷新 |

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **端末差で物理結果がずれる** | 致命的 | 決定論的物理（固定小数点）＋サーバリプレイ検証。**P0で全端末マトリクス検証を通すまで先に進まない** |
| デイリー1回制限で離脱 | 大 | フリー解体モードで受け止める／通知設計を丁寧に（朝9時＋夜の未プレイ通知の2回まで） |
| **UA費の高騰** | 大 | 動画ループでオーガニック60%を狙う。CPI $1.50超で即UA停止する規律を先に決めておく |
| 実在建築物の権利 | 中 | **実在建築は一切使わない**。全て架空デザイン。法務レビューを図鑑追加ごとに実施 |
| 「破壊」表現の審査リスク | 中 | 人・生物を一切登場させない／血・爆発の生々しい表現を避ける／**災害連想を避けるため地震モチーフは使わない**。TikTok連動でバズった Smash Fest! が Google Play から削除された前例があるため、審査ガイドラインの事前レビューを必須化 |
| スコア偽装 | 中 | サーバ側リプレイ検証。改ざん検知時は**順位から除外するだけでBANしない** |
| 短尺動画への飽き | 中 | シーズンごとに物理そのものを変える（氷は砕ける、砂は流れる）＝動画の絵面が変わる |

## 11. ローンチ戦略

**T-90日**：ソフトローンチ（カナダ / フィリピン / トルコ）。**この段階では一切バズらせない。** 数字だけ取る。
**T-45日**：TikTok / Shorts で **プレイ動画のみ**を毎日投稿する公式アカウントを開設。ゲーム名を出さず、崩壊映像だけで再生数を積む。
**T-21日**：解体・建築・物理シミュレーション系のクリエイター（**ゲーム系ではない**）200名に先行アクセス。「本物の解体工法が正解になる」という切り口は、建設系クリエイターに刺さる。
**T-0**：グローバル同時公開。**初日の盤面は最も映える1本**を用意する（初日に投稿される動画の数が全てを決める）。
**T+1〜14日**：毎日の盤面を**手作業で調整**。バズった日の盤面の特徴を分析し、翌週の自動生成パラメータに反映する。
**T+30日**：第1回「世界解体選手権」（週末48時間の特別盤面、国別対抗）。メディア露出の山をここに置く。

## 12. 補足：この企画の位置づけ

本企画は **5本中で最もバズの上限が低く、最も収益が安定している**。
- #1 GHOST CROWD と #4 EXCUSE ME! は「当たれば巨大、外せばゼロ」のハイボラティリティ枠。
- 本企画は **毎日9時に通知が届く習慣資産**であり、一度刺されば数年単位でDAUが減らない。

**ただし初期投資6,000万円＋UA 3億円は、他企画の当たりが1本出るまで投じるべきではない。**
→ ポートフォリオ上、**#3 または #1 のヒット後に着手する「収益の柱」候補**として位置づける。
