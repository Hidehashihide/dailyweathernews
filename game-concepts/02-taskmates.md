# 企画書 #2 『TASKMATES』（タスクメイツ）

**仮邦題：仕事中の相棒**
バズスコア **56 / 70** ｜ ベット経路：**日常寄生・常駐（TBH: Task Bar Hero 型）**

---

## 1. ログライン

> **あなたが仕事をしている間、画面の隅の相棒が勝手に他人の画面へ遠征し、戦利品を持って帰ってくる。**

## 3. なぜ今これか（市場根拠）

- **TBH: Task Bar Hero** が「タスクバーで動く放置RPG」だけで **ピーク同接513,272人・Steam全体4位**（CS2/PUBG/Dota 2の次）を取った。基本無料・2026年5月27日リリース・6日で20万同接。
- モバイルゲームの最大の競合が **TikTok / Instagram / YouTube の短尺動画** になった＝「時間を奪うゲーム」は負ける局面に入った。**時間を奪わないゲームが勝つ。**
- 一方 TBH は **RMT目的のBOT大量流入**と**誤BAN**で大きく評判を落とした。**この事故は経済設計で回避可能であり、そこが明確な参入余地**。
- Discord のデータ：**友達が1人いるとプレイ時間は中央値6倍、3人で8倍**。常駐ゲームにソーシャルを載せる価値は定量的に証明されている。

## 4. コアループ

```
[働いている間]
  タイピング・アプリ切替・静かな時間 → 「集中力」という資源に変換される
  ↓
[相棒が育つ] 集中力で装備を作る／レベルが上がる
  ↓
[遠征フェーズ] あなたがPCを離れると、相棒が自動でフレンドの画面へ遠征に出る
  ↓
[帰還] お土産を持ち帰る / あるいは奪われて帰ってくる
  ↓
[週次] 所属ギルド（会社・学校・Discordサーバー）単位で集計・順位発表
```

**重要**：プレイヤーが操作する時間は **1日あたり合計90秒以内** を目標とする。それ以上触らせない。

## 5. 詳細ルール

### 5-1. 資源の作り方（プライバシー設計が最重要）
| 入力 | 変換 |
|---|---|
| キー入力の**回数のみ** | 集中力 +1 / 100打 |
| アプリのフォアグラウンド**切替回数** | 少ないほど「集中ボーナス」 |
| 無操作の継続時間 | 「休息」＝相棒の体力回復 |

**絶対に行わないこと（設計上の不可変ルールとして明文化）**
- キーの**内容**は一切取得しない（回数のみ）
- アプリ名・ウィンドウタイトル・URL は**取得も送信もしない**
- スクリーンショットを撮らない
- サーバへ送るのは **抽象化された整数スコアのみ**。ローカル集計→日次1回送信。
- 初回起動時に、**何を取り、何を取らないかを1画面で明示**し、同意を取る。

> これは倫理面の配慮であると同時に、**最大の差別化・マーケティングメッセージ**でもある。「キーロガーでは?」という疑念は常駐アプリ最大の離脱要因であり、先に潰しておく。

### 5-2. 遠征と略奪（原則⑥の実装）
- 相棒は **フレンドの画面のみ** に遠征する（無差別マッチングはしない＝嫌がらせ防止）。
- 奪えるのは **「お土産」＝装飾アイテムの一時的な借用権** のみ。**恒久資産は絶対に奪われない**。
- 奪われた側には「取り返しクエスト」が自動発行され、**必ず取り返せる**（報復の快感だけを残し、損失は残さない）。

### 5-3. 「画面共有事故」を意図的に設計する
- 相棒は平常時は極小（16px相当）。だが **1日2回だけ、ランダムなタイミングで大きなイベント**が起きる（ボス出現・宝箱・相棒の失恋など）。
- これが会議の画面共有中に発生すると、**その場が笑いになる**。
- **「静音モード」ボタン**を常に1クリックで押せる場所に置く（配慮とネタは両立する）。

## 6. バズ設計

### 6-1. 7原則マッピング

| 原則 | 点 | 実装 |
|---|---|---|
| ①5秒ルール | **7** | 「会議中のタスクバーで小さい奴が事件を起こしている」画。文脈がやや必要 |
| ②失敗こそコンテンツ | **6** | 画面共有事故／遠征失敗／相棒の間抜けな死 |
| ③人間が乱数 | **6** | 遠征先はフレンドの実生活次第。相手が休日だと相棒が長居する等 |
| ④摩擦ゼロ | **10** | 無料・常駐・DL後すぐ動く・そもそも「プレイ」しない |
| ⑤日常寄生 | **10** | 仕事時間そのものが資源。**起動する理由が要らない** |
| ⑥所有と略奪 | **9** | 遠征と借用権の奪い合い。ただし恒久損失なし |
| ⑦ミーム代謝 | **8** | 相棒の衣装・イベントを週次更新。祝日カレンダーに事前固定 |

### 6-2. 想定クリップ（具体的に3本）

1. **「会議中にバレた」**
   画面共有中、タスクバーで相棒がボスに殺される。プレゼン中の本人だけが気づいていない。
   → 職場あるある系として、ゲーム外のフォロワーにまで届く。

2. **「同僚と戦争になった」**
   隣の席の同僚のフレンド申請を承認した結果、毎日お土産を奪い合うようになり、朝礼で言及される。
   → 「職場でTASKMATES戦争が起きている」という**現実世界の物語**が拡散する。

3. **「徹夜明けの相棒」**
   夜通し作業すると相棒が疲弊した姿になり、翌朝「休め」と言ってくる。
   → 感情移動。スクショが「今日の自分」としてXに貼られる。

### 6-3. 拡散の仕掛け
- **週次レポート画像の自動生成**：集中力・遠征成績・ギルド順位を1枚のカードにして毎週金曜に生成。そのままSNSに貼れる縦型。
- **ギルドが実在コミュニティと一致する**：Discordサーバー / 会社 / 学校で作れる。**招待の動機が「ゲームに誘う」ではなく「うちのチーム強くしよう」になる**（I値が跳ねる）。
- **OBSオーバーレイ公式対応**：配信者は相棒を配信画面に置ける。視聴者がチャットから相棒に差し入れできる（Twitch拡張）。

## 7. 収益モデル

| 種別 | 価格 | 内容 |
|---|---|---|
| 装飾（コスメ） | $1.99〜$9.99 | 相棒の見た目・エフェクト・タスクバーのテーマ |
| シーズンパス | $4.99 / 2ヶ月 | 限定装飾のみ。**ゲーム内の強さには一切影響しない** |
| ギルドバナー | $9.99 | ギルド単位の装飾。1人が買えば全員に表示 |
| **売らないもの** | — | **集中力・装備・遠征成功率など、性能に関わる全て** |

**なぜ性能を売らないか**：資源が「実労働時間」由来である以上、性能を売ると **「金で仕事したことにできる」** 構造になり、ゲームの前提が崩壊する。同時にこれがBOT対策にもなる（下記）。

**試算（基本ケース）**
- DAU 30万 × ARPDAU $0.02 = 日商 $6,000 → **月商 約2,700万円**
- サーバ費：日次1回の整数送信のみなので DAU 30万でも **月100万円以下**
- 損益分岐：**DAU 約4万**

## 8. TBH の事故を踏まない経済設計（本企画の中核）

| TBHで起きたこと | 本企画の対策 |
|---|---|
| RMT目的のBOTがサーバを圧迫 | **資源はアカウント間で移動不可**。通貨も装備もトレード機能を実装しない。**売る対象が存在しないのでRMTが成立しない** |
| BOTが放置で資源を稼いだ | 資源は「キー入力回数」由来だが、**1日の上限をハードキャップ**（人間が働ける現実的上限で頭打ち）。BOTで24時間回しても上限に当たるため経済的価値が出ない |
| 過剰なアンチチートで誤BAN | **BANを実装しない**。異常値検知時は「その日の資源を上限値に丸める」だけ。アカウントは決して停止しない |
| サーバ負荷 | クライアント側でローカル集計 → **日次1回だけ整数を送信**。常時同期をしない |

> **設計思想**：「不正を罰する」のではなく、**「不正しても得しない」構造にする**。罰する設計は必ず誤検知で無実のユーザーを傷つける。

## 11. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **「キーロガーでは」という疑念** | 致命的 | 取得項目の全公開／**クライアントの通信部分をオープンソース化**／第三者監査レポートを公開 |
| 会社PCへのインストール禁止 | 大 | 個人PC／スマホ版を用意。**企業向けに"情シス向け説明資料"を公式配布**（取得項目一覧・通信先一覧） |
| 常駐アプリのセキュリティ警告 | 中 | コード署名を初日から取得。Windows SmartScreen 対策として早期に評判を積む |
| TBHの二番煎じと見られる | 中 | **「ソーシャル遠征」と「プライバシー設計」を前面に**。TBHは単独放置、本作は関係性ゲーム |
| 相棒が邪魔だという批判 | 中 | 静音モード／表示サイズ3段階／**完全非表示でも遊べる**（レポートだけ見る層を許容） |
